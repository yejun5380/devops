# 2주차 - DevOps 기초 및 Git 파일 관리

## 1. 학습 목표

- DevOps의 기본 개념 이해
- Git과 GitHub를 이용한 파일 관리 방법 학습
- 텍스트 파일을 통한 기본 실습 내용 확인

## 2. DevOps 기본 개념

DevOps는 개발(Development)과 운영(Operations)을 결합한 개념으로, 개발과 운영 과정에서 협업과 자동화를 통해 소프트웨어를 효율적으로 제공하는 것을 목표로 한다.

Git은 파일의 변경 이력을 관리하는 버전 관리 도구이며, GitHub는 Git 저장소를 원격으로 관리하고 협업할 수 있는 플랫폼이다.

## 3. 실습 파일

### hello.txt

파일 내용:

```text
hi
```

### text.txt

파일 내용:

```text
Hello, DecOps!
```

두 텍스트 파일을 통해 저장소에 포함된 기본 파일과 내용을 확인하였다.

## 4. Git 기본 명령어 정리

| 명령어 | 기능 |
|---|---|
| git status | 현재 저장소의 변경 상태 확인 |
| git add | 변경 파일을 스테이징 영역에 등록 |
| git commit | 변경 사항을 로컬 저장소에 기록 |
| git push | 로컬 커밋을 원격 저장소에 업로드 |
| git pull | 원격 저장소의 변경 사항 가져오기 |
| git branch | 브랜치 목록 확인 |
| git switch | 작업 브랜치 변경 |

위 명령어는 Git 파일 관리에 사용되는 기본 명령어를 정리한 것이다.

## 5. 학습 내용 정리

DevOps와 Git의 기본 개념을 정리하고, 저장소의 텍스트 파일을 확인하였다.

파일의 변경 이력을 Git으로 관리하면 작업 내용을 추적할 수 있으며, GitHub를 통해 변경 사항을 공유하고 협업할 수 있다.
